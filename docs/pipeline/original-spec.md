# 오리지널 문항 작성 명세 (PMBOK 8판 · 2026 개정 시험)

목표: 2026년 7월 9일 개정 PMP 시험(ECO People 33 / Process 41 / Business Environment 26, 180문항·240분, PMBOK 8판이 주요 참고서)에 맞춘 **새로 쓴(오리지널) 상황 판단형 문항**.

## 금지
- 실제 시험 문제·덤프(ExamTopics 등)·수험서·학원 자료를 베끼거나 재구성하지 말 것. 웹 검색 금지.
- `private/` 폴더는 열지 말 것(학원 자료, 저작권).
- 중복 방지를 위해 `src/data/generated/*.json`(기존 오리지널)은 읽어도 된다. 같은 상황·같은 논점을 반복하지 말 것.

## 검증된 PMBOK 8판 사실 (이것만 사실로 사용)
- 2025년 11월 발행. 6원칙: 전체론적 관점 채택(Adopt a Holistic View), 가치에 집중(Focus on Value), 프로세스와 인도물에 품질 내재화(Embed Quality into Processes and Deliverables), 책임 있는 리더가 되라(Be an Accountable Leader), 모든 프로젝트 영역에 지속가능성 통합(Integrate Sustainability Within All Project Areas), 권한 위임 문화 구축(Build an Empowered Culture).
- 7성과 영역: 거버넌스, 범위, 일정, 재무, 이해관계자, 자원, 리스크. 5중점 영역: 착수·기획·실행·감시및통제·종료. 40개 프로세스(비규범적·테일러링 가능, ITTO).
- AI 활용, 지속가능성, 가치 실현, PMO, 조달·현대적 계약 방식을 다룬다.
- 7판: 12원칙, 8성과 영역(이해관계자, 팀, 개발 방식·생애주기, 기획, 프로젝트 작업, 인도, 측정, 불확실성), 가치 인도 시스템.
- 확실하지 않은 8판 세부(프로세스 개별 이름, 부록 번호 등)는 쓰지 말 것.

## 형식 구성 (담당 분량 기준)
- 단일 정답 4지선다: 약 70%
- 복수 선택(보기 5개, 지문에 "2개를 고르시오"/"3개를 고르시오"): 약 12%
- **사례형(case study)**: 약 15%. 개정 시험은 사례 지문 세트로 시작한다. 같은 사례로 2~3문항을 만들되 각 문항 stem 앞에 `[사례: 제목] 사례 본문(3~5문장)`을 반복해 넣어 문항마다 독립적으로 풀 수 있게 한다. tags에 "사례형" 포함.
- 짝 맞추기형: 약 3%. "다음 중 올바르게 짝지어진 것은?" 형식의 4지선다로 표현.
- 계산·표 해석(해당 주제만): 지문 안에 표를 텍스트로 제시. 숫자는 두 번 검산.
- 개발 방식 비율: predictive 약 50%, agile 약 25%, hybrid 약 25%.

## 품질 규칙
- 지문 2~5문장, 구체적 맥락(산업·역할·수치). 정답은 PMI 마인드셋: 서번트 리더십, 먼저 분석 후 행동, 팀 차원 해결 우선, 변경은 통합 변경 통제, 윤리·규정 즉시 대응, 가치·결과 중심, 테일러링.
- 정답이 논쟁적이거나 두 보기가 동등하게 맞으면 버리고 다시 쓴다. 작성 후 문항마다 스스로 재검토.
- **보기 길이 편향 금지**: 단일 정답 문항에서 정답 보기가 가장 긴 오답의 1.6배를 넘지 않게. 오답에도 근거 절("~하므로 ~한다")을 붙이고, 1/3 이상은 오답이 가장 긴 보기가 되게.
- answer 인덱스는 0~3에 고르게 분산.

## 필드 (모두 한국어, 핵심 용어는 괄호에 영어 병기)
id, domain(people|process|business), edition("8th": 8판 고유 개념이 정답 근거 / "both": 판 무관), approach, topic, tags(1~3), stem, options, answer(인덱스 배열), explanation(2~3문장), optionNotes(보기별 한 문장, 개수=보기 수), intent(이 문제가 확인하는 역량 1문장), perspective(PMI가 보는 관점 1~2문장), tip(풀이 팁 1문장), diffNote(8th 문항만: 7판과 무엇이 다른지 1~2문장).
topic은 domain에 맞는 아래 목록 중 정확히 하나:
- people: 리더십·서번트리더십, 팀개발·팀헌장, 갈등관리, 이해관계자참여, 의사소통, 협상, 동기부여·성과관리, 가상팀·다양성, 코칭·멘토링·교육, 감성지능·윤리적행동, 의사결정·권한위임
- process: 통합·변경통제, 범위·요구사항, 일정, 원가·EVM, 품질, 자원, 리스크, 조달·계약, 애자일실무(백로그·스프린트), 칸반·흐름, 추정, 하이브리드·테일러링, 종료·인계·교훈
- business: 전략정렬·가치, 편익실현, 거버넌스·PMO, 규정준수, 윤리, 조직변화관리, 외부환경변화, 지속가능성·ESG, AI·디지털전환

## 출력·검증
지정된 경로에 JSON 배열 하나(UTF-8, 2칸 들여쓰기). 저장 후 python3로 검증하고 통과할 때까지 수정:
JSON 파싱, 개수, id 중복 없음, answer 범위, optionNotes 길이 = options 길이, topic이 목록 안, 필수 필드 존재, 길이 편향(정답 ≤ 최장 오답 × 1.6).
최종 보고(짧게): 파일 경로, 문항 수, 형식·approach·edition 분포, 다룬 주제 한 줄.
