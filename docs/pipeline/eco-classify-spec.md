# 문항 → 2026 ECO 과제 분류 명세

기준: PMI 공식 PMP Examination Content Outline – July 2026의 26개 과제. 과제별 세부 항목(enabler)은 `docs/pipeline/eco-2026-tasks.txt`를 반드시 읽고 판단한다.

코드표:
- People: P1 공동 비전 수립 / P2 갈등 관리 / P3 프로젝트 팀 리딩 / P4 이해관계자 참여 / P5 이해관계자 기대 정렬 / P6 이해관계자 기대 관리 / P7 지식 이전 / P8 의사소통 계획·관리
- Process: R1 통합 계획·인도 방식(개발 방식 선택·테일러링 포함) / R2 범위 개발·관리 / R3 가치 기반 인도 / R4 자원 계획·관리 / R5 조달 계획·관리 / R6 재무 계획·관리 / R7 품질 계획·최적화 / R8 일정 계획·관리 / R9 프로젝트 상태 평가 / R10 프로젝트 종료
- Business Environment: B1 거버넌스 수립 / B2 규정 준수 / B3 변경 관리·통제 / B4 장애물 제거·이슈 관리 / B5 리스크 계획·관리 / B6 지속적 개선 / B7 조직 변화 지원 / B8 외부 환경 변화 평가

규칙:
- 문항이 **실제로 평가하는 판단**이 어느 과제의 enabler에 해당하는지로 고른다. 산업·소재가 아니라 "PM이 무엇을 하는가"가 기준.
- 2026 ECO에서 위치가 바뀐 것에 주의: 리스크→B5, 변경 통제·변경 요청→B3, 이슈·장애물 제거→B4, 거버넌스·PMO·단계 게이트·의사결정 권한→B1, 회고·교훈을 통한 프로세스 개선→B6, 의사소통 계획→P8, 지식·교훈 이전→P7.
- ECO에 독립 과제가 없는 주제: 윤리 위반·법규→B2, 윤리적 리더 행동→P3, 지속가능성은 문항의 판단에 따라(공급업체 선정이면 R5, 규정이면 B2, 외부 변화면 B8 등), AI 활용은 판단 대상에 따라(거버넌스·정책이면 B1, 품질 검증이면 R7 등).
- EVM 등 성과 측정·상태 보고 문항은 R9, 예산·자금·원가 산정은 R6.
- 애매하면 가장 직접적인 과제 하나만 고른다.

출력: JSON 객체 하나 `{"<문항 id>": "<코드>", ...}`를 지정 경로에 저장(UTF-8). 저장 후 python3로 입력 문항 수와 키 개수가 같은지, 모든 값이 위 26개 코드 중 하나인지 검증.
최종 보고(짧게): 파일 경로, 문항 수, 코드별 개수. 문항 원문은 보고에 쓰지 말 것.
